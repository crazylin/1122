# Avalonia 3D 控件演示

这是一个基于Avalonia UI框架的3D控件演示应用程序，展示了如何使用Avalonia内置功能创建具有3D效果的立体控件。

## 功能特性

### 3D控件类型
- **3D按钮**: 可点击的立体按钮控件，带有阴影效果
- **3D滑块**: 可拖拽的立体滑块控件，带有阴影效果
- **3D开关**: 可切换的立体开关控件，带有阴影效果
- **3D进度条**: 立体进度显示控件，带有阴影效果
- **3D文本框**: 立体文本输入控件，带有阴影效果

### 交互功能
- 动态添加和移除3D控件
- 实时调整控件大小
- 自定义控件间距
- 控件状态实时反馈
- 拖拽和点击交互

### 视觉效果
- 阴影效果模拟3D深度
- 可调节的控件大小
- 自动排列布局
- 响应式设计

## 技术栈

- **Avalonia UI**: 跨平台UI框架
- **.NET 8**: 运行时环境
- **Canvas布局**: 灵活的控件定位
- **阴影效果**: 模拟3D视觉效果

## 运行要求

- .NET 8.0 或更高版本
- Windows, macOS, 或 Linux 系统

## 构建和运行

1. 确保已安装 .NET 8.0 SDK
2. 克隆或下载项目文件
3. 在项目目录中运行以下命令：

```bash
# 还原依赖包
dotnet restore

# 构建项目
dotnet build

# 运行应用程序
dotnet run
```

## 使用说明

### 基本操作
1. **添加3D控件**: 点击顶部工具栏中的按钮来添加不同类型的3D控件
2. **调整控件大小**: 使用右侧面板的"控件大小"滑块调整所有控件的大小
3. **调整控件间距**: 使用"控件间距"滑块调整控件之间的间距
4. **清除控件**: 使用"清除所有"按钮移除所有3D控件

### 控件交互
- **3D按钮**: 点击显示反馈信息
- **3D滑块**: 拖拽改变值，实时显示当前值
- **3D开关**: 点击切换状态，显示当前状态
- **3D文本框**: 输入文本，实时显示内容
- **3D进度条**: 显示固定进度值

### 自定义设置
- **控件大小**: 0.5x 到 2.0x 可调
- **控件间距**: 1.0 到 5.0 可调
- **实时预览**: 所有设置立即生效

## 技术特点

### 3D效果实现
- 使用`DropShadowEffect`创建阴影效果
- 不同控件使用不同的阴影参数
- 阴影偏移和模糊半径可调

### 布局管理
- 使用Canvas进行绝对定位
- 自动计算控件位置
- 响应式布局调整

### 事件处理
- 控件状态变化实时反馈
- 用户交互即时响应
- 信息面板动态更新
